# 🤖 n8n AI Agents

A growing collection of AI agent and automation workflows built in [n8n](https://n8n.io) — exploring practical, real-world use cases for AI agents, RAG pipelines, and business automation.

Each folder is a self-contained project with its own workflow export and README explaining how it works.

## 📂 Projects

| # | Project | Description |
|---|---------|-------------|
| 01 | [AI Chatbot](./01-ai-chatbot) | A conversational AI chatbot built with n8n's Chat Trigger and AI Agent node |
| 02 | [AI Agent with Tools](./02-ai-agent-with-tools) | An AI agent equipped with custom tools to take real actions, not just chat |
| 03 | [Email Summarizer Agent](./03-email-summarizer-agent) | Automatically summarizes incoming emails using an AI agent |
| 04 | [RAG Pipeline Chatbot](./04-rag-pipeline-chatbot) | A Retrieval-Augmented Generation chatbot using Pinecone for vector storage and Google Drive as a document source |
| 05 | [Doc Q&A Agent](./05-doc-qa-agent) | Ask natural-language questions about an uploaded document and get context-aware answers |

## 🛠️ Tech Stack

- **n8n** — workflow orchestration and automation
- **OpenAI (GPT-4o-mini)** — chat and reasoning
- **Google Gemini** — embeddings
- **Pinecone** — vector database for RAG
- **Vapi** — voice AI (upcoming project)

## 🎯 About This Repo

This is a hands-on practice log for building AI agent and automation systems — each project tackles a different pattern (chatbots, tool-using agents, RAG, document Q&A) that can be adapted into real business solutions like customer support bots, AI receptionists, and internal knowledge assistants.

New projects are added regularly as part of ongoing daily practice.
